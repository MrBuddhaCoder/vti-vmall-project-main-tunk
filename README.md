# VTI VMall Project

An online shopping mall application built by VTI - A comprehensive platform for managing e-commerce store operations.

## Overview

This is a primary project using mainly **Java** (99.7%) with a small portion of **HTML** (0.3%) for web interface.

## Technology Stack

- **Java** - Primary programming language
- **HTML** - Markup for web interface

## Installation Guide

1. Clone the repository:
```bash
git clone https://github.com/MrBuddhaCoder/vti-vmall-project-main-tunk.git
cd vti-vmall-project-main-tunk
```

2. Build the project:
```bash
mvn clean build
```

3. Run the application:
```bash
mvn spring-boot:run
```
